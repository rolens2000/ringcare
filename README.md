# AI 링케어 (RingCare)

2026 AI 라이프 솔루션 챌린지 출품 시제품입니다. 연계 아이디어는 「13번. 케어브릿지」입니다.

스마트링 생체신호, AI 음성대화, 요양보호사 메모를 교차검증해 독거 어르신과 요양병원 와상 환자의 위기를 우선순위로 알리고, 돌봄 기록 초안을 자동으로 작성합니다.

> **바로 체험:** https://rolens2000.github.io/ringcare/ (로그인 없이 PC·휴대폰, 기본 분석 모드)
>
> **시연 영상:** https://youtu.be/eQ54c0Ha3p4 (2분 39초)
>
> **현장 의견조사:** https://rolens2000.github.io/ringcare/survey/ (응답은 저장하지 않고 카카오톡으로 회신)

> 모든 인물은 가명이며 데이터는 합성 데이터입니다. 인지 관련 결과는 의료적 진단이 아닙니다.

## 기능

| 화면 | 내용 |
|---|---|
| 돌봄 대시보드 | 가상 인물 10명(재가 6, 요양병원 와상 4)을 위험도순으로 정렬하고, 판단 근거·권장 조치·기준선 그래프를 보여줌 |
| AI 안부대화 | 식사·수면·기분·통증 질문, 음성(크롬·엣지) 또는 글로 답변, 그날 링 신호와 교차검증 |
| 케어브릿지 메모 | 메모를 8개 항목 한국어 기록 초안으로 정리, 원문 근거 표시, 미확인 정보 보류, 7개 언어 받아쓰기(녹음 미저장) |
| 돌봄 기록 | 센서·대화·메모를 출처별로 모아 기록 초안 자동 작성, 수정 시 자동 저장(브라우저 저장소), 담당자 승인 후 확정, 승인 후 가족 공유, CSV 내보내기 |
| 검증 결과 | 합성 시나리오 1,080건 판단 검증, 기록 초안 24건 평가, 실측 CSV 분석 |

## 구조

```
index.html                  시제품 전체(화면 + 판단 로직), 외부 라이브러리 없음
api/ai.js                   생성형 AI 연동 함수(Vercel용, 선택). 환경 변수 ANTHROPIC_API_KEY 필요
netlify/functions/ai.mjs    같은 함수의 Netlify용
survey/index.html           현장 의견조사 페이지(서버 저장 없음)
tools/engine.js             판단 엔진 원본(개인 기준선, 교차검증, 기록 초안, 검증)
tools/app.html              화면 원본
tools/build.js              app.html + engine.js → index.html 생성
```

## 실행

- 브라우저로 `index.html`을 열면 기본 분석 모드로 작동합니다.
- 테스트 URL(GitHub Pages)은 정적 호스팅이라 기본 분석 모드로 작동합니다. 이 저장소를 Vercel에 가져오면(`api/ai.js`) 또는 Netlify에 Git 연동하면(`netlify/functions/ai.mjs`) 서버 함수가 함께 배포되며, 환경 변수 `ANTHROPIC_API_KEY`를 넣으면 생성형 AI 모드(번역, 기록 초안, 대화 위험 표현)를 쓸 수 있습니다(실서버 검증은 후속 과제).
- 검증 다시 실행: `node -e "const R=require('./tools/engine.js'); console.log(R.runValidation(10).cross, R.evalDrafts().fieldAcc)"`
- 화면 다시 생성: `node tools/build.js` (tools/app.html과 tools/engine.js를 합쳐 index.html을 만듦)

## 판단 방식

1. 시간대별 개인 기준선: 최근 14일의 시간대별 중앙값과 MAD
2. 재가 탐지 6종: 장시간 정지, 심박 이탈, 착용 중단, 야간 활동, 피부온도 상승, 활동량 급감
3. 와상 탐지 5종: 체위 변경 지연, 발열, 심박 이탈, 야간 초조, 새벽 침상 이탈 시도
4. 교차검증: 링 신호 × AI 대화 응답 × 메모 확인 사항 → 안정 / 주의 / 위기

## 기록 초안 원칙 (케어브릿지 사전질의 답변 반영)

- 원문을 함께 보여주고, 항목마다 근거와 출처(메모·센서·대화)를 표시
- 메모에 없는 시점·섭취량·정도·복약 여부는 채우지 않고 "미기재·확인 필요"로 보류
- 진단·처방·건강위험 판정·복약 지도를 하지 않음
- 담당자 수정·승인 후 확정, 가족 공유는 승인 뒤에만
- 상시 녹음 없음. 받아쓰기는 누를 때만 작동하며 녹음 파일을 남기지 않음
- 장기요양급여제공기록지를 대체하거나 공단에 자동 입력하지 않음

## 한계

- 시나리오·정답·평가 메모를 개발자가 만들었으므로 수치는 실제 현장 성능이 아닙니다.
- 기본 분석은 정해진 표현만 인식합니다. 다른 표현·언어는 생성형 AI 모드가 필요합니다.
- 링은 손 움직임만 측정하므로 체위 변경은 "지연 의심"으로만 표시합니다.
- 실기기 연동, 실제 전화 발신, 현장 실증은 후속 과제입니다.
